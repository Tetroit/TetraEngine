# TetraEngine
A C++ OpenGL rendering engine made solely by me

### Features:
- #### Rendering
  - Skybox
  - Pipelines
    - Blinn-Phong
    - (NEW) Blinn-Phong 4D
    - *PBR (Coming soon)*
  - Material system
  - User-defined shaders
  - Directional and point lights
  - Object parenting
- #### UI
  - Component-wise inspector
  - Tree hierarchy
  - Viewport
- #### Architecture
  - Subscriber-based event system
  - Edit mode/game mode
  - ECS architecture for game objects
  - Resource manager with async loading (WIP)
  - *Scene serialization (Coming soon)*
  - Multiple applications  
- #### (NEW) Physics
  - Collision & trigger callbacks
  - Sphere/Cube colliders
